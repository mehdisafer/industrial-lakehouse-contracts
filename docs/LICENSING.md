# Licensing and third-party scope

## Original project code

No open-source licence has been selected for the original Industrial Lakehouse
Contracts code. Making a repository visible is not a decision to grant MIT,
Apache-2.0 or another redistribution licence. This preview therefore does not
include a fabricated licence grant or an SPDX identifier for the project.

The repository is intended to make the implementation and evidence inspectable.
Any future licensing decision must be explicit, cover the correct copyright
holder and preserve third-party notices. Platform-provided viewing/forking rights
are not described here as an unrestricted reuse licence.

## Dependencies and external products

Python dependencies, upstream API specifications, container images and CI tools
retain their own licences. A referenced or downloaded container is not relicensed
by this repository. No OpenMetadata, PostgreSQL, Elasticsearch, JDK or Gitleaks
binary is committed as original project code.

The Compose files and qualification harness describe an original synthetic
integration. Upstream schema and deployment references are recorded in
[OPENMETADATA_LIVE.md](OPENMETADATA_LIVE.md) and [SOURCES.md](SOURCES.md).
No claim is made that every transitive dependency has passed legal or security
review. No employer/client material is eligible for a contribution.
